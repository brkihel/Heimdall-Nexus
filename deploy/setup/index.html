01 / 05

Onde o site vai morar?

Informe o domínio que apontará para esta máquina. Você também pode usar um IP e configurar HTTPS depois.

O assistente configurará o Nginx para este endereço.
Deixe em branco para usar o mesmo domínio.
Usado pelo Let’s Encrypt para avisos de renovação.
Antes de continuar

O link temporário usa a rede Cloudflare e termina quando o instalador fecha. Guarde o endereço com token em privado. Para evitar esse serviço externo, rode install.sh com --local-only e use SSH.

02 / 05

Seu mundo Valheim

SteamCMD baixará o servidor oficial. O mundo será salvo em /srv/valheim/saves, separado dos arquivos do jogo.

Valheim usa esta porta e a seguinte.
Obrigatória, com pelo menos 5 caracteres e sem repetir o nome do servidor. Os jogadores digitam essa senha para entrar.
Rede

Com o backend Steam, encaminhe as portas UDP escolhida e seguinte no firewall e roteador. Com crossplay, o Valheim usa um relay.

03 / 05

Escolha os recursos

Instale somente o que faz sentido para o seu servidor. As páginas e layouts serão editados depois no painel.

Opcional. Cole o link da página do modpack na Thunderstore ou no Hexium. Também aceita Autor/Modpack ou o caminho completo de um .zip enviado à VPS (com mods privados). Um modpack publicado também preenche a lista de mods do site.

Dados ao vivo no editor

Estes grupos aparecem como peças arrastáveis. Recursos que dependem de mods exigem a configuração correspondente.

04 / 05

Proteja o painel

Escolha uma conta Linux para o serviço do painel e um login separado para o site. A senha do painel será guardada como hash.

Conta criada na VM para executar o painel; diferente do login abaixo. O jogo usa outra conta separada.
Acesso

Depois da instalação, acesse /jarl/entrar. O editor visual da página fica disponível após o login.

05 / 05

Tudo pronto para instalar

Revise o resumo. O download do Valheim pode levar alguns minutos; acompanhe cada etapa nesta tela.

O que será instalado

SteamCMD, Valheim Dedicated Server, serviço systemd, Nginx, site e painel. BepInEx será incluído se você o selecionou.
