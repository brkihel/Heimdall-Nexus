# Visual editor

[Português](pt-BR/Editor.md) · [Wiki home](Home.md)

Sign in at /jarl/entrar and open **Site → Full screen editor**. Choose a page from the selector. Click text to edit it. The left sidebar provides blocks, live data, page settings, structure and versions. Drag a design into the page or click to add it beside the selected block. Use the Link tool for on-page anchors, other pages, external URLs and email.

Changes remain a draft until **Save**. Undo and redo work across text and block changes. **Preview** makes a temporary link for review. The save check warns about broken anchors, empty blocks and images without descriptions. Each publication creates a version; the Versions tab can preview and restore earlier states.

## Appearance

Open **Aparência** in the panel menu to set the identity of the whole site:

- **Name, slogan, footer and site address.** Shown on every page, in browser tabs and in shared links.
- **Logo, favicon and background.** The logo replaces the name at the top of the home page. The background is used by blank pages. SVG images with scripts are refused.
- **Colors.** A global table of 14 colors applies to every page. Start from a palette and adjust; the sample shows the result before saving.

**Salvar e publicar** applies everything to the pages and republishes the site. Previous files are kept on the server.

## Pages

In **Aparência → Páginas**, create a page from a template:

- **Wiki format:** side index, sections, highlight boxes and tables.
- **Blank page:** only the site header, background and footer.

Choose a title and address (for example `/rules/`). The page is published immediately and appears in the editor's page selector. To let visitors reach it, point a button or link to it with the Link tool. **Remover** unpublishes the page and keeps a copy of its file. The home page cannot be removed.

The initial site is a neutral sample. Replace the placeholder text before sharing yours.
